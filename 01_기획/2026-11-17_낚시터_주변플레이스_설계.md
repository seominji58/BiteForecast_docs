# 낚시터 정리 + 주변 플레이스(낚시점·대여·낚시배) 설계

2026-11-17 · 초안

## 1. 지금 문제

운영 기준 장소 219곳 (`backend/seeds/places.json`):

| 출처 | 수 | 문제 |
|---|---|---|
| 전국낚시터정보표준데이터 | 162 | 전부 `paid`(유료 바다낚시터·좌대형). 갯바위·방파제 같은 일반 포인트가 아님. 대상 어종은 「우럭+참돔+농어+점성어 등」 같은 홍보 문구(오타 「참동」 포함). 시설(`facility`) 대부분 비어 있음 |
| 국립해양조사원 바다낚시지수 지점 | 49 | 「목포북항서측(53km)」처럼 **항구 기준 바다 위 좌표**. 사람이 가는 장소가 아닌데 낚시터처럼 목록·지도에 섞여 나옴 |
| 수동 지정 (OSM 좌표) | 8 | 좌표만 있음 |

- 사진이 하나도 없다 → 목록이 글자만 나열돼 어떤 곳인지 판단이 안 된다
- 「이 근처에서 채비를 사거나 장비를 빌릴 수 있나」 정보가 없다 (30~60대 이용자가 출조 전에 가장 많이 찾는 것)

## 2. 목표

1. 장소를 **종류별로 분리**해서 「바다 위 지수 지점」이 낚시터처럼 보이지 않게 한다
2. 낚시터 상세·지도 카드에 **주변 플레이스**(낚시점·미끼·장비 대여·낚시배)를 거리순으로 보여준다
3. 자세한 정보·사진·리뷰는 **네이버 지도(또는 카카오맵) 장소 화면으로 연결**한다 — 앱이 사진을 복사해 저장하지 않는다

## 3. 장소 종류 정리 (데이터 변경 없음, 표시 규칙만)

| 종류 | 대상 | 화면 표시 |
|---|---|---|
| 낚시터 | 표준데이터 유료낚시터, 수동 지정 | 지금처럼 목록·지도 핀 |
| 바다 포인트 (선상) | 지수 지점 49곳 | 「○○항 남서 14km 바다」 · 「선상 낚시 기준점」 꼬리표. 출조계획에 넣을 때 「배를 타고 가는 곳」 안내 |
| 주변 플레이스 (신규) | 낚시점·대여·낚시배 | 낚시터 상세·지도 카드 아래 「근처」 목록. 지도 핀으로는 뿌리지 않음(핀이 너무 많아짐) |

- 표시 이름 규칙: `강릉항북동(2km)` → `강릉항 북동쪽 2km 바다` (원본 이름은 그대로 두고 표시만 바꿈)
- 대상 어종 원문은 「낚시터가 알린 대상 어종」으로 출처를 밝혀 그대로 보여준다. 오타 교정은 하지 않는다(원문 보존)

## 4. 주변 플레이스 데이터 출처

| 후보 | 얻을 수 있는 것 | 한계 |
|---|---|---|
| **카카오 로컬 API (키워드 검색)** | 좌표 기준 반경 검색, 이름·분류·전화·주소·좌표, 카카오맵 장소 링크(`place_url`) | 사진 없음. 결과 저장·노출 조건은 약관 확인 필요 |
| **네이버 검색 API (지역)** | 이름·분류·주소·좌표·링크 | 한 번에 최대 5건, 반경 검색 없음(검색어로만). 사진 없음 |
| **네이버 지도 앱/웹 링크** | 장소 화면(사진·리뷰·영업시간)으로 이동 | 연결만 가능, 데이터는 못 가져옴 |
| 해수부 낚시어선업 신고대장 (2021, 약 7만 행) | 출입항명·최대 승객 수 | **업체명·연락처 없음**, 2021년 기준. 「이 항구에서 출항하는 낚시어선 N척」 같은 참고 숫자로만 |

권장: **카카오 로컬로 찾고, 상세는 네이버 지도로 연결**.
앱 지도가 이미 카카오맵이라 좌표·반경 검색이 자연스럽다.
사용자가 원하면 같은 이름으로 네이버 지도 검색 링크도 함께 제공한다.

### 검색어 (낚시터 좌표 반경 5km, 거리순)

| 분류 | 검색어 |
|---|---|
| 낚시점·미끼 | 낚시점, 낚시마트, 미끼 |
| 장비 대여 | 낚시 대여, 낚싯대 대여 |
| 낚시배 | 낚시배, 선상낚시 |

- 결과의 분류명에 「낚시」가 없는 곳은 뺀다 (검색어만 걸린 식당 등 제거)
- 결과가 없으면 「근처에서 찾은 곳이 없어요 · 네이버 지도에서 찾아보기」 링크만 보여준다 (가짜 결과 없음)

## 5. 화면

**낚시터 상세 · 지도 핀 카드 → 「근처」**

```
근처 낚시점·대여              네이버 지도에서 더 보기 ›
[낚시점] 대부낚시마트   1.2km   📞  지도 ›
[대여]   ○○레저        2.8km   📞  지도 ›
[낚시배] △△호 선상낚시 3.1km   📞  지도 ›
출처: 카카오 로컬 · 영업 여부는 전화로 확인하세요
```

- 행을 누르면 장소 화면(외부)으로 이동, 📞는 바로 전화
- 출조계획 상세 「개요」에도 첫 낚시터 기준 「근처 낚시점」 2곳까지
- 사진: 앱에 저장하지 않는다. 장소 사진은 외부 링크에서 본다
  - 낚시터 자체 대표 사진은 다음 단계에서 **이용자 인증 사진 중 공개 동의한 것**만 사용

## 6. 구현 구조

```
앱 → GET /places/{id}/nearby?kind=shop|rental|boat
        → 백엔드가 카카오 로컬 호출 (API 키는 서버에만)
        → 짧게 캐시 (약관 허용 범위, 예: 하루) → 거리순 반환
```

```
NearbyPlace { name, kind, category, phone, address, lat, lon, distance_m,
              kakao_url, naver_search_url, source, fetched_at }
```

- 이미 있는 `/geo/search`(카카오 로컬 키워드 대행 · REST 키는 서버에만 · 1시간 캐시)의 호출·캐시 방식을 그대로 재사용하고, 좌표·반경(`x`,`y`,`radius`)과 분류 거르기만 더한다
- 새 DB 테이블 없이 시작 (요청 시 조회 + 캐시). 많이 쓰이면 그때 저장 테이블 검토
- 네이버 연결 링크: `https://map.naver.com/p/search/{이름 주소}` (앱 설치 시 네이버 지도 앱 스킴으로)

## 7. 단계

| 단계 | 내용 |
|---|---|
| 1차 | 장소 종류 분리 표시 (지수 지점 → 바다 포인트), 표시 이름 규칙 |
| 2차 | `/nearby` API + 낚시터 상세 「근처」 목록 (카카오 로컬) + 네이버 지도 링크 |
| 3차 | 지도 카드·출조계획 개요에 근처 2곳, 낚시어선 수(공공데이터) 참고 표시 |
| 4차 | 낚시터 대표 사진 = 공개 동의한 인증 사진 |

## 8. 확인 필요

- 카카오 로컬·네이버 검색 API 약관: 결과 캐시 기간, 화면 표시 조건(출처 표기), 호출 한도
- 네이버 플레이스 사진·리뷰는 API로 가져올 수 없음 → 링크 연결만
- 낚시어선업 신고대장 최신판(2021 이후) 있는지 공공데이터포털 재확인

## 9. 구현 결과 (2026-11-18)

- **1차 완료** (앱): 선상 지수 지점 15곳 이름을 「목포북항 서쪽 53km 바다」로 표시, 지수 지점 49곳은 상세·지도 카드에 「배를 타고 가는 바다 위 지점 · 공식 낚시지수 기준점」 안내. 원본 이름·데이터는 그대로 (`frontend/src/lib/place.ts` `placeName`·`placeKindNote`)
- **2차 완료** (서버 `GET /places/{id}/nearby` + 낚시터 상세 「근처 낚시점·낚시배」)
  - 실제 카카오 결과를 보고 정한 규칙: 낚시점 = 「낚시점」 반경 5km, 낚시배 = 「선상낚시」 반경 15km, 분류에 「낚시」 없는 결과(펜션·민박)와 「낚시 > 낚시터」(유료낚시터)는 제외, 거리순 8곳
  - **장비 대여는 따로 분류하지 않음**: 「낚시 대여」 검색 결과가 낚시점과 같은 가게들이라 구분 근거가 없음 → 「대여 여부는 전화로 확인」 안내만
  - 「낚시배」·「낚시어선」 검색어는 결과 0건 → 「선상낚시」 사용
  - 좌표가 없거나 의심(D등급)인 낚시터는 검색하지 않고 이유를 표시
  - 서버 1시간 메모리 캐시 (`/geo/search`와 같은 방식)
- 남은 것: 3차(지도 카드·출조계획 개요에 근처 2곳), 카카오 약관(캐시·출처 표기) 확인
