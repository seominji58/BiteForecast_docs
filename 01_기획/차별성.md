# 차별성

> 한 줄 소개: **공식 데이터로 오늘의 바다를 믿고 확인하고, 잡고 싶은 어종에서 출조 계획·조황 기록까지 하나로 이어지는 낚시인의 공간**

| # | 기존 방식의 불편 | 입질예보는 | 구현 근거 |
|---|---|---|---|
| 1 | 물때·파고·풍속·특보를 여러 사이트·앱에서 따로 확인 | **한 화면에서** 날짜·지역별로 확인 | 기상청 단기예보·특보 + 국립해양조사원 조석·부이·낚시지수를 매시 자동 수집해 한 API 로 제공 |
| 2 | 「어디서, 무엇을」 찾는 데 시간이 걸림 | **어종에서 시작하는 탐색** — 잡고 싶은 어종 → 공식 지수 지점 → 포인트 → 출조계획 | 공식 바다낚시지수 8종·49지점 오전/오후 등급, 홈 어종 카드 → 포인트 보기 → 목표 어종 자동 입력 |
| 3 | 출처를 알 수 없는 점수·추천 | **기관 발표값을 그대로**, 출처·발표 시각과 함께. 앱이 조황 점수를 만들지 않음 | 예보/실측 구분, 「○시 발표」 표시, 자료가 없으면 0 대신 「자료 없음」 |
| 4 | 낚시터 위치가 틀려 엉뚱한 바다 정보를 보는 위험 | **위치 정확도 검증** — 좌표가 의심되는 곳은 해황 연결·추천에서 제외 | 219곳 좌표 품질 등급(A~D)·검증 이력, 주소 API 대조, 근처 지점 지수는 「참고」로 구분 |
| 5 | 「특보 없음」인지 「확인 못 함」인지 알 수 없음 | **안전 정보는 보수적으로** — 확인 불가를 「없음」으로 표시하지 않음 | 특보 상태 세분화(해역 모름·자료 만료·수집 실패 구분), 지금 발효 기준 명시 |
| 6 | 파고·풍속 숫자만으로는 감이 안 옴 | **쉬운 말로 풀어서** — 「낮은 물결」「건들바람」「사리 무렵」 + 용어 풀이 | 세계기상기구 파랑 등급·보퍼트 풍력 등급·기상청 특보 기준으로 작성 |
| 7 | 정보 확인과 출조 준비·기록이 따로 놂 | **준비부터 기록까지 한 흐름** — 출조계획(날짜별 장소·예비 장소·준비물) → 그날 해황 요약 → 다녀와서 기록 | 출조계획 API·화면, 계획 장소에서 「기록 남기기」 연결 |
| 8 | 커뮤니티 조황의 신뢰도 | **믿을 수 있는 조황 커뮤니티** — 사진 인증 조황, 가짜 조황·사진 없음 | 관리자 사진 검토 후 인증·포인트·칭호, 테스트 계정 글 분리 |
| 9 | 개인 프로젝트는 운영이 멈추기 쉬움 | **저비용 자동 운영** — 서버·DB·수집이 사람 손 없이 계속 동작 | Fly.io(도쿄)·Supabase(서울)·GitHub Actions 매시 수집, 월 약 $2 수준 |

## 핵심 3가지
1. **어종 중심 탐색** — 「어떤 물고기를 잡으러 가세요?」에서 시작해 공식 낚시지수 지점과 출조계획까지 바로 이어진다
2. **믿을 수 있는 공공데이터** — 기관 발표값을 출처·시각과 함께 그대로, 위치가 의심되거나 자료가 없으면 솔직하게 「확인 불가」
3. **경험을 잇는 커뮤니티** — 출조 준비 → 낚시 → 인증 조황 기록·공유가 한 앱에서
