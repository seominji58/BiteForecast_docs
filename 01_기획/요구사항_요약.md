# 요구사항 요약

해결하려는 문제와 서비스 방향은 [기획 의도](기획의도.md) 참고.

## 3. 사용자 흐름

1. 홈에서 잡고 싶은 어종을 고른다 (상관없이 볼 수도 있음).
2. 출조 날짜·지역(또는 내 주변)을 고른다.
3. 오늘의 낚시 정보(파고·풍속·물때·특보)를 확인한다. 칸을 누르면 뜻을 볼 수 있다.
4. 포인트 보기에서 공식 지수 지점 또는 일반 낚시터를 확인한다.
5. 낚시터 상세에서 예보·실측·물때·공식 지수의 출처와 시각을 확인한다.
6. 출조계획에 추가한다 (목표 어종 자동 입력).
7. 출조 전 기상청 원문과 현장 출입 제한을 다시 확인하고, 다녀와서 기록·조황을 남긴다.

## 4. 정확성·안전 원칙

- 공식 낚시지수 `좋음`은 조황·안전 보장이 아니다.
- 풍랑주의보가 직접 적용되는 장소는 낚시지수와 무관하게 조건 충족 후보로 처리하지 않는다.
- `인근 해역 특보`, `적용 해역 확인 불가`, `자료 만료`, `수집 실패`를 서로 섞지 않는다.
- 예보·실측은 별도 계열로 표시한다.
- 결측값을 실제 0으로 채우지 않는다.
- 원본 좌표와 좌표 품질 등급은 변경하지 않는다.
