# 입질예보 발표용 요구사항 요약

## 1. 해결하려는 문제

낚시터를 고를 때 파고·풍속·물때·특보·공식 낚시지수가 여러 기관과 화면에 흩어져 있어, 사용자가 출조 전 조건을 비교하기 어렵다.

입질예보는 등록 낚시터와 공공 해양 데이터를 연결해 사용자가 **어디를 확인할지 빠르게 좁히고, 상세 자료를 직접 확인하도록 돕는 서비스**다.

## 2. 핵심 요구사항

| ID | 요구사항 | 구현 상태 |
|---|---|---|
| R-01 | 지역·낚시터 검색과 지도 탐색 | 구현 |
| R-02 | 날짜별 파고·풍속 예보 및 실측 구분 | 구현 |
| R-03 | 조석 예보와 관측소 거리 표시 | 구현 |
| R-04 | 기상청 해상 특보와 적용 해역 표시 | 구현·세부 고도화 중 |
| R-05 | 국립해양조사원 공식 바다낚시지수 표시 | 구현 |
| R-06 | 사용자가 정한 파고·풍속 기준으로 조건 필터 | 구현 |
| R-07 | 특보 발효·자료 부족·좌표 의심 장소를 추천 후보에서 제외 | 구현 |
| R-08 | 출조계획·준비물·장소별 예보 확인 | 구현 |
| R-09 | 낚시일지·사진·포인트·커뮤니티 | 구현 범위 포함 |
| R-10 | 실제 조황·입질·어획 확률을 임의로 예측하지 않음 | 필수 원칙 |

## 3. 사용자 흐름

1. 홈에서 지역·날짜·내 주변을 선택한다.
2. `내 기준에 맞는 낚시터` 후보를 확인한다.
3. 특보와 자료 신선도를 확인한다.
4. 장소 상세에서 물때·예보·공식 낚시지수의 출처와 시각을 확인한다.
5. 비교하거나 출조계획에 추가한다.
6. 출조 전 기상청 원문과 현장 출입 제한을 다시 확인한다.

## 4. 정확성·안전 원칙

- 공식 낚시지수 `좋음`은 조황·안전 보장이 아니다.
- 풍랑주의보가 직접 적용되는 장소는 낚시지수와 무관하게 조건 충족 후보로 처리하지 않는다.
- `인근 해역 특보`, `적용 해역 확인 불가`, `자료 만료`, `수집 실패`를 서로 섞지 않는다.
- 예보·실측은 별도 계열로 표시한다.
- 결측값을 실제 0으로 채우지 않는다.
- 원본 좌표와 좌표 품질 등급은 변경하지 않는다.
