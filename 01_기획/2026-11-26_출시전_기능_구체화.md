## A. 전국 낚시 탐험 — 스탬프

### A-1. 시즌 1 장소: 공식 바다낚시공원 18곳

지금 후보 34곳(항구·방파제·해변)은 시군 낚시통제구역 확인이 안 끝나 **검증 완료 0곳**이다. 반면 **바다낚시공원·해상낚시터는 지자체·어촌계가 운영하는 「낚시하라고 만든 시설」**이라 낚시 가능 여부를 따로 검증할 필요가 없고, 관리자·안전시설이 있다 (일본 국토교통성 「낚시문화 진흥 모델항」과 같은 원칙: 관리 주체가 있는 개방 시설만).

서버 낚시터 자료(전국낚시터정보표준데이터·관광공사)에 있는 곳, 실내 낚시터 제외:

| 바다 | 곳 |
|---|---|
| 서해 (11) | 선재낚시공원 · 영흥바다낚시터 · 용담바다낚시터 (옹진) · 선두바다낚시터 · 황청낚시터 · 황산초지바다낚시터 (강화) · 소래바다낚시터 (인천 남동) · 갈음이 해상낚시공원 · 안면도 라암도 해상낚시공원 (태안) · 원산도 선촌 해양낚시터 (보령) |
| 남해 (7) | 지세포 낚시공원 (거제) · 통영등대낚시공원 · 돌산해양낚시공원 (여수) · 거금해양낚시공원 (고흥) · 득량만바다낚시공원 (보성) · 정남진 해양낚시공원 (장흥) · 가우도 복합낚시공원 (강진) |
| 동해 (1) | 당사해양낚시공원 (울산 북구) |

- 동해·제주가 비어 있다 → 시즌 1은 「서해·남해 낚시공원」, 동해·제주는 후보 34곳 검증이 끝나는 대로 시즌 2로
- 곳마다 **운영 여부·이용 요금·휴장일**을 확인해 카드에 적는다 (전화·누리집 확인, 출시 전 1회)
- 기존 후보 34곳 화면(미리보기)은 「시즌 2 준비 중」 탭으로 남긴다

### A-2. 방문 인증 (체크인)

| 항목 | v1 | 이후 |
|---|---|---|
| 방법 | **「도장 찍기」 버튼 → 지금 위치가 장소 300m 안이면 도장** (위치 권한은 이미 있음 · 누를 때만) | 앱 안 촬영 사진 + GPS (해외 MyCatch 방식, 카메라 권한 추가 필요) · 낚시공원 매표소 QR |
| 막는 조건 | 그 바다 **해상 특보 발효 중** · 해진 뒤~해뜨기 전 · 같은 곳은 하루 1번 | 위치 조작 탐지 |
| 저장 | 장소 id · 시각 · 거리 구간(100m 안/300m 안)만. **좌표는 저장하지 않는다** | — |
| 공개 | 내 도장첩은 나만. 커뮤니티에는 「○○ 탐험가」 칭호만 | 친구 비교 |

### A-3. 보상

- 새 장소 도장 **+20P** (같은 곳은 처음 한 번) — 기존 포인트·칭호 표(point_ledger)에 「탐험 도장」 사유 추가
- 바다별 완주 배지 (서해 낚시공원 n/11 …), 시즌 완주 시 칭호 「낚시공원 탐험가」
- 포인트는 기존 규칙처럼 현금 가치 없음

### A-4. 서버 · 화면

- 표: `challenge_spot`(장소·시즌·운영 정보·상태) · `challenge_visit`(사용자·장소·시각·거리 구간) — Alembic 0012
- API: `GET /challenge/spots` · `POST /challenge/spots/{id}/visit` (위치는 요청에만 쓰고 저장 안 함) · `GET /me/challenge`
- 화면: 지금 미리보기 화면에 「시즌 1 낚시공원」 탭 + 장소 시트에 「도장 찍기」 + 내정보 「내 도장첩」

## B. 입질예보에게 묻기 (AI 챗봇)

### B-1. 무엇을 답하나 — 「우리 자료로 확인되는 것만」

AI가 바다 상태를 추측하지 않게, 답하기 전에 **우리 서버 자료를 조회하는 도구**만 쓰게 한다 (OpenAI 함수 호출).

| 도구 | 쓰는 자료 | 예시 질문 |
|---|---|---|
| 낚시터 찾기 | 낚시터 237곳 이름·지역 | 「거금도 낚시공원 어디야?」 |
| 그날 해황 요약 | 기상청 예보·실측, 물때, 특보 | 「내일 남애항 바람 어때?」 |
| 어종별 지수 | 국립해양조사원 바다낚시지수 | 「이번 주말 감성돔 어디가 좋아?」 |
| 특보 | 기상청 특보 현황 | 「지금 서해 특보 있어?」 |
| 금어기·금지체장 | 수산자원관리법 요약 | 「지금 주꾸미 잡아도 돼?」 |
| 용어 풀이 | 앱 용어 풀이 | 「사리가 뭐야?」 |

### B-2. 답하지 않는 것 (고정 문구로 거절)

- 먹어도 되는지·독 여부·손질 → 「안전 문제라 답하지 않아요」
- 출조 강행 여부 판단(「이 정도 바람이면 가도 돼?」) → 수치·특보만 보여 주고 「판단은 공식 특보와 현장 상황으로」
- 우리 자료에 없는 장소·날짜 → 「자료가 없어요」 (지어내지 않음)
- 답마다 **근거 출처·발표 시각**을 붙이고, 앱 화면(낚시터 상세·금어기)으로 가는 버튼을 단다

### B-3. 화면 · 제한

- 입구: 홈 검색창 옆 「묻기」, 낚시터 상세 「이 낚시터 물어보기」(장소가 미리 채워짐)
- 추천 질문 칩 3개로 시작 (빈 화면 방지)
- 로그인 필요 · **하루 20번** · 서버 전체 하루 한도 · 대화는 기기에만(서버 저장 안 함)
- 모델: gpt-5.4-mini (어종 찾기와 같은 키). 질문 1번 = 도구 호출 1~3번 + 답 → 비용은 출시 후 실사용으로 측정
- 개인정보 처리방침 「국외 이전」에 「질문 내용」 추가

| **국가어항구역** | 항구 낚시터 상세 | 「국가어항(해양수산부)」 정보 | 금지 근거 아님 — 참고 |
| 해양보호구역 | 상세 | 「해양보호구역 안」 주의 | 금지 근거 아님 |

- 모두 **「판정」이 아니라 「공식 자료 안내」** — 「낚시 가능」으로 표시하지 않는다
- 자료마다 출처·기준일을 붙이고, 설정 「데이터 출처」 목록에 추가

## 1. 결정할 것

1. **출시 범위**
   - ① 출시 먼저, 세 기능은 첫 업데이트 (출시 가장 빠름)
   - ② **C + A(시즌 1)까지 넣고 출시**, 챗봇(B)은 첫 업데이트 ← 추천: C는 작고 안전 정보라 출시판 품질을 올리고, A는 차별점이 분명하며 장소 검증 문제를 낚시공원으로 피했다. B는 답 품질 검수에 시간이 걸린다
   - ③ 셋 다 넣고 출시 (3~5일 늦어짐)
2. 시즌 1 낚시공원 18곳의 **운영 여부 확인**을 누가 할지 (전화·누리집 — 제가 누리집으로 먼저 정리하고, 애매한 곳만 전화)
3. 탐험 도장 포인트 +20P가 적당한지 (기록 10P · 첫 어종 15P · 개인 최대어 20P와 비교)
