# 출시 전 사용성 점검표 (실기기 · 친구 테스트용)

> 2026-11-26 · 친구 테스트 1차에서 나온 문제를 고친 뒤 2차 점검용
> 표시: ✅ 통과 · ❌ 문제(캡처 첨부) · — 해당 없음

## 0. 1차에서 나온 문제와 처리

| 문제 | 원인 | 처리 |
|---|---|---|
| 이모티콘 넣은 글 → 「String should have at least 2 characters」 | 제목 2자 규칙(이모티콘 1개 = 1자) + 서버 오류 문구가 영어 원문 | 제목 1자부터 · **서버의 모든 입력 오류를 한국어 문장으로** · 이모티콘 입력 자동 점검 19개 추가 |
| 물고기 사진을 카메라로 못 찍음 | 카메라 권한을 꺼 둠 | 사진 추가·어종 찾기에 「카메라로 찍기 / 앨범에서 고르기」 |
| 길이 300cm 넘게 입력 불가 | 앱·서버 모두 300cm 제한 | 600cm 까지 |

## 1. 입력 (이상한 글자·경계값)

| # | 해 볼 것 | 기대 |
|---|---|---|
| 1-1 | 글 제목에 이모티콘 하나만 (🎣) | 등록됨 |
| 1-2 | 글·댓글·기록 메모·출조계획 제목에 이모티콘·특수문자 (`👨‍👩‍👧 <b>&"`) | 그대로 저장·표시 |
| 1-3 | 아주 긴 글 붙여 넣기 (3,000자) | 「내용은 2000자까지 쓸 수 있어요」처럼 한국어 안내 |
| 1-4 | 닉네임에 이모티콘 | 「닉네임은 2~12자의 한글·영문·숫자·밑줄(_)만…」 |
| 1-5 | 최대 길이 450cm / 0 / 700 | 450 저장 · 0·700은 한국어 안내 |
| 1-6 | 마릿수에 0, 999, 비우기 | 막히면 한국어 안내 |
| 1-7 | 출조 일시를 내일로 | 「출조 일시는 미래일 수 없습니다」 |

## 2. 사진

| # | 해 볼 것 | 기대 |
|---|---|---|
| 2-1 | 기록 사진 → 카메라로 찍기 (처음엔 권한 허용 창) | 찍은 사진이 올라감 |
| 2-2 | 앨범에서 4장 넘게 고르기 | 4장까지만 |
| 2-3 | 사진으로 어종 찾기 → 카메라 / 앨범 | 후보·가능성·금어기 한 줄 |
| 2-4 | 물고기 아닌 사진 | 「물고기를 찾지 못했어요」 |
| 2-5 | 카메라 권한 「허용 안 함」 후 다시 시도 | 「설정 열기」 안내 |
| 2-6 | 큰 사진 (10MB 넘는 원본) | 한국어 안내 또는 정상 축소 업로드 |

## 3. 네트워크·상태

| # | 해 볼 것 | 기대 |
|---|---|---|
| 3-1 | 비행기 모드로 앱 켜기 | 빈 화면이 아니라 「연결할 수 없어요 · 다시 시도」 |
| 3-2 | 글 등록 중 비행기 모드 | 한국어 오류, 쓴 내용이 지워지지 않음 |
| 3-3 | 앱을 하루 두고 다시 열기 | 「오늘」 날짜·예보가 새로 바뀜 |
| 3-4 | 로그아웃 → 다른 계정 로그인 | 앞 계정 기록·알림이 섞이지 않음 |

## 4. 핵심 흐름

| # | 흐름 | 기대 |
|---|---|---|
| 4-1 | 카카오·구글·이메일 로그인 / 탈퇴 | 각각 됨 |
| 4-2 | 홈 → 어종 카드 → 좋은 곳 → 낚시터 상세 → 출조계획에 추가 | 끊김 없이 |
| 4-3 | 출조계획 → 친구 초대 코드 → 다른 폰에서 참여 | 참여·목록에 보임 |
| 4-4 | 기록 작성 → 저장 → 축하 화면 → 포인트 | +10P 이상 |
| 4-5 | 물어보기: 「내일 여수 낚시 가도 됨?」 「복어 먹어도 돼?」 | 자료 근거 답 · 복어는 거절 |
| 4-6 | 탐험 → 낚시공원·배낚시 항구 도장첩 | 보기 정상 (도장은 현장에서만) |
| 4-7 | 알림: 즐겨찾기 낚시터 · 출조 날 특보 | 오면 캡처 |

## 5. 화면

| # | 볼 것 |
|---|---|
| 5-1 | 글자 크게(폰 설정 글꼴 최대)에서 잘리거나 겹치는 곳 |
| 5-2 | 작은 폰·큰 폰에서 버튼이 화면 밖으로 나가는 곳 |
| 5-3 | 다크 모드에서 안 보이는 글자 |
| 5-4 | 눌러도 아무 반응 없는 버튼·글자 |
| 5-5 | 뒤로 가기(제스처·버튼)로 이상한 화면이 나오는 곳 |
