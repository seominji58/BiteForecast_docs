## 1. 지금 홈의 문제 (화면 확인 기준)

| 영역 | 지금 | 문제 |
|---|---|---|
| 상단 검색 | 네이비 상자 안에 문구 2줄 + 검색창 + 큰 버튼 2개 (약 210pt) | 첫 화면의 1/3 을 차지, 정보는 없음 |
| 최근 조황 | 실제 글이 0개라 큰 빈 상태 카드 | 가장 좋은 자리에 「없어요」가 보임 |
| 오늘 출조 탐색 | 「전국 108곳」 숫자 + 지역 드롭다운 | 숫자만 크고 실제 낚시터가 안 보임. 지역을 골라야 목록이 나오는데 눈에 잘 안 띔 |
| 낚시 소식·정보 | 글자 메뉴 3줄 | 단조롭고, 공공데이터의 가치가 안 보임 |
| 전체 | 흰 카드가 세로로 반복 | 시각적 위계가 없음 |

## 3. 데이터 연결 검증 (219곳, 2026-11-09)

### 3-1. 결과와 처리

| 항목 | 결과 | 처리 |
|---|---|---|
| 파고·풍속 예보 | 219곳 연결 | — |
| 부이 실측 | 73곳 | 없는 곳은 「실측 없음」 |
| 바다낚시지수 | 10km 안 90곳 | 129곳은 멀어서 표시 안 함 (기존) |
| 조위(물때) | 15km 안 같은 바다 110 · 15~30km 같은 바다 84 · **다른 바다 13** · 30km 안 관측소 없음 12 | **다른 바다 13곳은 물때 표시 안 함** (`DIFFERENT_SEA`) |
| **좌표 오류** | **충남 서산시 6곳**(우리·만석·김선장·대호·항구·백년낚시터, id 177~182)이 원본 CSV 에서 부산 좌표(35.2672, 129.0183) | 「위치 확인 필요」(`LOCATION_CHECK`): 해황·특보를 연결하지 않고 출조 후보·지도에서 뺌. **DB 좌표는 바꾸지 않음** |

- 물때 대표성은 거리만으로 판단하지 않는다: 관측소가 보는 바다(그 관측소에서 가장 가까운 좌표 정상 낚시터의 특보 해역)와 낚시터의 특보 해역이 겹칠 때만 「참고 자료」로 연결한다.
- 좌표 의심 판정: 같은 시·도의 (좌표가 다른) 가장 가까운 낚시터가 60km 넘게 떨어져 있고, 다른 시·도 낚시터가 그 1/3 거리 안에 있으면 의심. (시·군 중앙값 방식은 서산 7곳 중 6곳이 같은 잘못된 좌표라 실패하고, 가거도·먼바다 포인트를 잘못 잡아 버렸다.)
- **승인 필요**: 서산 6곳의 실제 좌표 보정 — 주소(충남 서산시 대산읍 화곡리 등)로 지오코딩할 출처(예: 행정안전부 주소 API, 카카오 로컬 API 등)를 정해 주시면 보정 스크립트를 따로 만든다. 그 전까지는 위치 확인 필요로 둔다.

## 4. 홈 v3 구성 (위 → 아래)

```
┌ 상단 (네이비, 작게) ─────────────────────────┐
│ [검색: 지역·낚시터]                            │
│ [◎ 내 주변]  [▤ 지도 탐색]                    │
│ (오늘)(내일)(11/11 수)(11/12 목)…  ← 날짜 선택 │
└──────────────────────────────────────────┘
오늘의 출조 탐색                      기준 바꾸기 ›
(◎내 주변)(서해)(남해)(동해)(제주)
내 기준: 파고 ≤1m · 풍속 ≤7m/s · 특보 발효 제외
┌ 후보 카드 (최대 3) ─────────────────────────┐
│ [유형 아이콘] 낚시터 이름 / 지역·유형·거리  상세 › │
│ [파고 최대 0.5m] [풍속 최대 4m/s] [특보 없음]     │
│ 다음 만조 14:20 · ○○ 관측소 기준               │
└──────────────────────────────────────────┘
지역별 바다 상황                       전체 지도 ›
[작은 지도: 실제 좌표 점 — 특보 발효 빨강 · 내 기준 충족 틸 · 기준 밖 회색 · 자료 부족 연회색]
선택한 낚시터의 해황
[물때 선 그래프(시간별 조위) + 만조·간조 시각 + 관측소 이름·거리·「참고 자료」]
[파고 예보 최대 | 풍속 예보 최대]  (각각 실측 최근값·부이 거리)
[해상 특보]
낚시 정보: [낚시 팁] [두 곳 비교] [금어기·안전]
최근 조황: 실제 글이 있을 때만 사진 카드 / 없으면 작은 「글쓰기 ›」 한 줄
```

### 규칙

| 영역 | 규칙 |
|---|---|
| 날짜 | 오늘 ~ 예보 범위 끝. 날짜를 바꾸면 후보·지도·해황이 그 날짜로 다시 계산된다. 미래 날짜는 「지금」 특보를 그날 특보로 쓰지 않는다(지금 발효 중이면 자료 부족 → 후보 제외, 카드에는 「특보 발표 전」) |
| 권역 칩 | 서해·남해·동해·제주는 기기에 저장. 「내 주변」은 누를 때만 위치 권한을 묻고(저장 안 함) 60km 안을 본다. 아무것도 고르지 않으면 후보를 내지 않고 안내만 |
| 후보 | 고른 날짜 예보로 **내 기준 충족**인 곳만, 최대 3곳. 특보 발효·자료 부족·좌표 의심은 절대 후보로 내지 않음. 정렬: 내 주변 = 가까운 순 / 권역 = 파고 예보 최대 낮은 순 → 풍속 낮은 순 (정렬 기준을 화면에 표시). 사진 없음 — 낚시터 유형 아이콘 정보 카드 |
| 후보 없음 상태 | 자료 오래됨 / 그 날짜 예보 없음(예보 끝 날짜 표시) / 자료 부족 / 0곳(이유별 곳 수) / 위치 거부(권역 고르라고 안내)를 각각 다른 문구로 |
| 작은 지도 | 고른 범위(없으면 전국)의 실제 좌표. 조작 없이 누르면 전체 지도(`/explore`). 범례에 상태별 곳 수 |
| 해황 대상 | 내가 고른 곳(검색·후보 카드 탭, 기기 저장) → 즐겨찾기 첫 곳 → 없으면 「낚시터를 고르면…」 안내. **최근 본 낚시터는 쓰지 않음**, 임의 낚시터 없음 |
| 물때 | 선 그래프(시간별 조위 예측) + 만조·간조. 관측소 이름·낚시터와 거리·「국립해양조사원 조석 예보 · 참고 자료」를 항상 표시. 다른 바다 관측소면 그래프 대신 이유 |
| 파고·바람·특보 | 각각 따로. 파고·풍속은 예보 최대(시각) + 오늘이면 실측 최근값(부이 거리) |
| 최근 조황 | 실제 조황 글이 있을 때만 카드. 없으면 큰 빈 카드 대신 한 줄 입구 |
| 기온·하늘 | 이번 범위 제외 (수집 확장 필요) |

### 디자인

- 브랜드 색(네이비·틸·주황)과 하단 탭 5개 유지. 상단 상자는 문구 2줄을 빼서 약 210pt → 약 180pt (날짜 선택 포함).
- 흰 카드 반복을 줄임: 후보만 카드, 지도·해황은 각 1장, 낚시 정보는 작은 타일 3개, 조황 없으면 한 줄.
- 글자: 본문 small 이상, 터치 영역 최소 36~44pt(날짜·칩 36~40, 상단 버튼 44). 긴 이름은 한 줄 말줄임으로 iPhone 폭에서 잘리지 않게.
- 물때 그래프는 추가 네이티브 모듈 없이(View 회전 선분) 그려 앱 재빌드가 필요 없다.

### v3.1 보완 (2026-11-09 사용자 피드백)

| 항목 | 변경 |
|---|---|
| 지도 겹침 | 화면 약 40px 격자로 가까운 낚시터를 **숫자 묶음**으로 표시. 묶음 색 = 가장 많은 상태, 특보 발효 곳이 섞이면 빨간 작은 숫자. 묶음을 누르면 그 범위로 확대, 「‹ 전체 범위」로 복귀 |
| 권역 이동 | 서해·남해·동해·제주·내 주변을 고르면 그 낚시터 범위(실제 좌표)로 지도가 이동. 후보 카드와 지도는 같은 범위·날짜로 함께 갱신 |
| 지도 → 해황 | 낚시터 점을 누르면 「선택한 낚시터의 해황」이 그 곳으로 바뀜(근거 「지도에서 고른 곳」, 지도에 주황 테두리) |
| 설정 아이콘 | 화면 오른쪽 위의 큰 파란 톱니는 **Expo 개발용 앱의 도구 버튼**이라 실제 앱에는 없다. 앱의 설정 버튼은 헤더의 작은 「설정」 글자 버튼(브랜드 스타일) 그대로 |
| 선택 안 함 안내 | 큰 카드 → 한 줄 안내 |
| 예보 범위 밖 날짜 | 날짜 칩에 「· 예보 전」 표시. 고르면 후보 대신 「예보 발표 전 (예보는 ○일까지)」, 지도는 모두 「예보 발표 전」 회색, 해황의 파고·풍속은 「발표 전」. 물때(조석 예측)는 자료가 있으면 그대로. 다른 날짜 값으로 대신하거나 조건 충족으로 표시하지 않음. 예보가 하루 일부만 있는 날(예: 끝 날짜 다음 날 00시 한 점)도 예보 발표 전으로 본다 |
