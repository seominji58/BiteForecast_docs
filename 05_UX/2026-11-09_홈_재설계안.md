# 홈 화면 재설계안 (검토용, 2026-11-09)

> 상태: **설계안 — 화면 코드는 바꾸지 않았다.** 승인 후 구현한다.
> 목표: 들어오자마자 「오늘 어디로 갈 수 있지?」에 답하고, 바다·출조 분위기를 느끼게 한다. 기능을 늘리기보다 순서와 형태를 바꾼다.

---

## 1. 지금 홈의 문제 (화면 확인 기준)

| 영역 | 지금 | 문제 |
|---|---|---|
| 상단 검색 | 네이비 상자 안에 문구 2줄 + 검색창 + 큰 버튼 2개 (약 210pt) | 첫 화면의 1/3 을 차지, 정보는 없음 |
| 최근 조황 | 실제 글이 0개라 큰 빈 상태 카드 | 가장 좋은 자리에 「없어요」가 보임 |
| 오늘 출조 탐색 | 「전국 108곳」 숫자 + 지역 드롭다운 | 숫자만 크고 실제 낚시터가 안 보임. 지역을 골라야 목록이 나오는데 눈에 잘 안 띔 |
| 낚시 소식·정보 | 글자 메뉴 3줄 | 단조롭고, 공공데이터의 가치가 안 보임 |
| 전체 | 흰 카드가 세로로 반복 | 시각적 위계가 없음 |

### 2-2. 추가 수집이 필요함 (이번 범위 아님 — 필요하면 별도 승인)

| 자료 | 방법 | 비고 |
|---|---|---|
| 기온·하늘 상태·강수 확률 | 기상청 단기예보에 이미 있는 항목(TMP·SKY·PTY·POP) — **수집기만 확장** | 같은 API·같은 인증키, 「맑음 14°C」 표시 가능 |
| 일출·일몰 | 한국천문연구원 출몰시각 API (**새 활용신청 필요**) | 새벽·저녁 출조에 유용 |
| 「7물」 같은 음력 물때 | 한국천문연구원 음양력 API 또는 국립해양조사원 물때 자료 (새 활용신청) | 지금은 대조기·중조기·소조기만 있음 |
| 조황 사진·소식 | 이용자 글뿐 — **현재 실제 글 0개** | 뉴스·임의 조황은 만들지 않는다 |

## 3. 새 홈 구성 (위 → 아래, 먼저 확인할 정보 순)

```
┌───────────────────────────────────────┐
│▓ 입질예보                      설정 ▓│ 앱바 (그대로)
│▓▓ 네이비→청록 그라데이션 + 물결 선 ▓▓▓│ ① 상단 (약 120pt, 지금의 60%)
│  11월 9일(일) · 물때 대조기 · 특보 41곳 │    오늘 한 줄 요약
│ [🔍 지역·낚시터 검색      ][◎][지도]  │    검색 한 줄 + 아이콘 버튼
├───────────────────────────────────────┤
│ 오늘 출조 후보        [제주][충남][경남]…│ ② 지역 칩 (가로 스크롤, 고른 지역 저장)
│ ┌─────────┐┌─────────┐┌─────────┐     │    + [◎ 내 주변] 칩
│ │김녕       ││월정리     ││성산포     │     │    후보 카드 2~3장 (가로)
│ │파고 ▁▂▃▂ ││파고 ▁▁▂▁ ││          │     │    · 예보 최대 파고·풍속(숫자+작은 막대)
│ │최대0.8m  ││최대0.5m  ││  …       │     │    · 다음 만조/간조, 공식 지수(있을 때)
│ │풍속5.1m/s ││풍속4.2m/s ││          │     │    · 내 기준 충족한 곳만 (특보 발효 제외)
│ │만조 20:21 ││간조 17:40 ││          │     │
│ └─────────┘└─────────┘└─────────┘     │
│ 제주 32곳 중 내 기준 충족 7곳 · 지도에서 ›│    근거 한 줄 + 지도 진입
├───────────────────────────────────────┤
│ 오늘 물때                  김녕 기준 ▾ │ ③ 물때·파고 그래프 (약 170pt)
│ 조위 ▁▃▅▇▅▃▁▁▃▅▇▆  ←지금              │    · 시간별 조위 막대 + 지금 표시
│ 만조 08:12 · 간조 14:14 · 만조 20:21    │    · 만조·간조 시각
│ 파고 예보 ▂▂▃▃▂▂▁▁ (최대 1.5m 15시)     │    · 파고 예보 막대 (같은 시간축)
├───────────────────────────────────────┤
│ 지역별 바다 상황 (기상청 예보·특보)      │ ④ 작은 지도 + 지역 요약 (약 200pt)
│ ┌ 작은 지도: 특보 발효(빨강)·인근(주황) ┐│    · 지도는 보기 전용, 누르면 낚시터 찾기
│ │ 낚시터 점                            ││    · 아래 가로 칩: 지역별 「파고 최대 범위
│ └──────────────────────────────────┘│      · 특보 n곳」
│ [제주 파고 0.5~2.0m 특보 5] [충남 …]   │
├───────────────────────────────────────┤
│ [💡 낚시 팁] [⚖ 두 곳 비교] [🛡 금어기] │ ⑤ 바로가기 아이콘 한 줄 (지금의 글자 메뉴 3줄)
├───────────────────────────────────────┤
│ 최근 조황 (글이 있을 때만 사진 카드)     │ ⑥ 실제 글이 생기면 사진 가로 카드로 나타남
│ 글이 없으면: 얇은 한 줄 「첫 조황 올리기 ›」│    없으면 한 줄만
```

### 영역별 상세

**① 상단 (높이 약 40% 줄임)**
- 네이비 → 청록 그라데이션 배경 + 아래쪽에 얇은 물결 모양 (그림 파일 없이 도형으로) — 바다 분위기
- 「오늘 한 줄」: 날짜 · **물때(대조기 등, 고른 지역의 공식 지수 기준)** · **해상 특보 발효 곳 수** — 모두 실제 자료. 자료가 없으면 해당 항목은 빼고, 오래됐으면 「자료 갱신 지연」 표시
- 검색창 한 줄 + 오른쪽에 아이콘 버튼 2개(내 주변 · 지도). 기능은 그대로

**② 오늘 출조 후보 (가장 중요한 영역)**
- 지역 칩: 낚시터가 많은 순 11개 + 「◎ 내 주변」. 고른 지역은 저장(지금과 같은 저장소)
- 지역·위치가 정해지면 **내 기준을 충족한 곳 2~3장**을 가로 카드로:
  - 정렬: 내 주변 → 거리순 / 지역 → 이름순 (임의 기준의 「가까운 순」 없음)
  - 카드 내용: 낚시터 이름·종류 아이콘, **오늘 남은 시간 예보 최대 파고·풍속**(숫자 + 시간별 작은 막대), 다음 만조·간조, 공식 바다낚시지수(있는 곳만), 실측(있는 곳만, 시각 표시)
  - **특보 발효·조건 밖·자료 부족 장소는 카드로 만들지 않는다**
- 아래 근거 한 줄: 「제주 32곳 중 내 기준 충족 7곳」 + 「지도에서 모두 보기 ›」
- 지역도 위치도 없으면: 카드 자리에 **지역 칩과 「◎ 내 주변 찾기」 버튼만 크게** (숫자 강조 없음)
- 고른 지역에 충족한 곳이 없으면: 「오늘 제주는 내 기준에 맞는 곳이 없어요」 + 제외 이유 1줄 + 기준 바꾸기
- 자료가 오래됐으면: 후보 카드 대신 마지막 갱신 시각 (지금 규칙 유지)

**③ 오늘 물때 그래프**
- 기준 낚시터: 최근 본 곳 → 없으면 ②의 첫 후보 → 없으면 영역 숨김 (임의 낚시터로 채우지 않음)
- 시간별 조위(국립해양조사원 예보) 막대 24개 + 「지금」 표시, 만조·간조 시각
- 같은 시간축에 파고 예보(기상청) 막대 — 「몇 시쯤 물이 들어오고 파도가 어떤지」를 한눈에
- 출처·관측소 거리 한 줄

**④ 지역별 바다 상황**
- 작은 지도(높이 140pt, 보기 전용): 낚시터 점을 특보 단계 색으로 (발효 빨강·인근/예비 주황·없음 청록). 누르면 낚시터 찾기 화면
- 아래 가로 칩: 지역별 「파고 예보 최대 0.5~2.0m · 특보 발효 5곳」 — 모두 실제 요약값으로 계산. 누르면 그 지역으로 ② 전환

**⑤ 바로가기 한 줄**
- 정보·팁(커뮤니티) · 두 곳 비교 · 금어기·안전 — 아이콘 3개 가로 배치 (지금의 글자 메뉴 3줄 대체)

**⑥ 최근 조황**
- 테스트 제외 실제 글이 **1개 이상**이면 지금의 사진 가로 카드 영역을 그대로 노출 (위치는 ② 바로 아래로 올림)
- **0개면 큰 빈 카드 대신 한 줄 배너** 「첫 조황을 올려 보세요 ›」만

### 화면 길이
- 아이폰 17 기준: 첫 화면에 ①·②가 다 보이고 ③ 일부가 보임. 전체 약 1.4화면 (지금 약 1.6화면)
- iPhone SE: 첫 화면에 ①과 ②의 카드 위쪽까지

## 4. 시각 구성 원칙
- 흰 카드 반복 대신: **그라데이션 상단 → 연한 청록 띠(출조 후보) → 흰 바탕 그래프 → 지도** 로 영역마다 배경을 바꿔 구분
- 가로 스크롤 카드(②·④·⑥)로 세로 길이를 줄인다
- 숫자 강조는 「예보 최대 파고·풍속」에만, 등급 표현은 지금처럼 공인 등급표(보퍼트·WMO)만
- 색: 네이비(배경)·청록(정상·충족)·주황(주의·주 버튼)·빨강(특보 발효) — 기존 브랜드 유지
- 그래프: 새 라이브러리 없이 막대(View)로. 색만으로 구분하지 않고 숫자·글자를 같이 둔다
