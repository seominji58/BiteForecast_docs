## 0. 환경 변경 기록

| 항목 | 내용 |
|---|---|
| Java | `brew install openjdk@17` — `/opt/homebrew/opt/openjdk@17`. **셸 설정(`~/.zshrc`)은 바꾸지 않음** (실행할 때 `JAVA_HOME` 을 지정) |

| 프로젝트 패키지 | 변경 없음 |
| 제거 | `brew uninstall maestro openjdk@17`, `brew untap mobile-dev-inc/tap`, `claude mcp remove maestro` |

## 5. UX 개선안 (구조 변경 — 승인 후)

1. **「파고 최대 0m」**: 기상청 예보값 0(0.25m 미만 반올림으로 추정)이 그대로 「0m」로 보여 자료가 없는 것처럼 보임 → 「0.5m 미만」 같은 표현 검토 (원자료 단위 확인 필요)
2. **지도 탐색 화면**: 핀 212개가 겹쳐 지도를 가림(`02x_explore`) → 홈 지도처럼 묶음 표시 도입
3. **주/예비 모두 예비일 때**: 「주 장소 없음」 안내 + 한 곳을 주 장소로 지정하도록 유도
4. **로그인 화면 비밀번호 칸**: 입력 자동화가 한 번에 안 들어가 두 번 시도 — 실제 사용자 영향은 없을 가능성 높음(테스트 도구 문제로 분류)
5. **홈 지도 묶음 원끼리 겹침**(남해 7·2 등) — 묶음 반경 조정 검토

## 6. 테스트 스크립트 문제 (앱 문제 아님)

- 하단 탭 이름이 「홈, tab, 1 of 5」로 읽혀 글자로 못 누름 → 위치로 누름
- 화면 밖으로 일부 잘린 날짜 칩·버튼은 글자로 못 찾음 → 밀어서 보이게 한 뒤 누름
- `back` 명령이 헤더 뒤로가기를 못 누름 → 위치로 누름
- 한 단계가 수십 초~수 분 걸리고 가끔 멈춤 → 시간 제한을 두고 실행
