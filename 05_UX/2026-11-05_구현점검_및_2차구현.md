## 2. 단계별 변경
1. **홈·상세 해황** — `sea-detail.tsx`(MetricTable·TideCard), `place/[id].tsx`, `sea-summary-card.tsx`
2. **비교** — `dropdown.tsx`(신규), `(tabs)/compare.tsx`, `compare-view.tsx`
3. **카테고리·어종** — `species-field.tsx`(신규), `community/new.tsx`, `(tabs)/community.tsx`
4. **사진 업로드** — 백엔드 `photo` 테이블·`/photos` API(EXIF·GPS 제거, 1600px, 10MB), 앱 `api/upload.ts`·`photo-picker.tsx`(expo-image-picker)
5. **인증** — 일지 `verification_*` 컬럼, 신청·취소 API, `/api/v1/admin` 검토 화면(ADMIN_TOKEN), 사전 검사(촬영 시각 차이·같은 사진 재사용)는 참고만
6. **포인트·내정보** — `services/points.py` 인증 완료 기준, `me.tsx` 인증 현황
7. **탐색 중심 홈 (사용자 제안 반영)** — `/places-summary` API, `explore.tsx`(지도·목록), 내 주변(GPS, 누를 때만), 조건으로 찾기(사용자 기준·공식 특보·공식 지수, 앱 판정 없음)

## 3. API·DB 변경
- 신규 API: `POST /photos`, `GET /photos/{id}`, `POST·DELETE /journals/{id}/verification`, `GET /admin/verifications`, `POST /admin/verifications/{id}/approve|reject`, `GET /admin`(검토 화면), `GET /places-summary`
- 기존 API 확장: 일지 입력 `photo_ids`·`request_verification`, 일지 응답 `photos`·`verification`·`shared_post_id`, 글 입력 `species_etc`·`photo_ids`·`journal_id`, 글 응답 `verified`·`photo_count`·`thumb`·`photos`·`catch`
- DB: `photo` 테이블 신설, `journal.verification_*` 4개, `post.species_etc`·`post.journal_id` 추가. **재생성 없이 컬럼 추가만** (백업: `backend/backups/…before-photo-verification.db`). 기존 사용자 8명·글 1건 유지, 기존 일지·포인트는 0건이라 회수 대상 없음
- 설정: `ADMIN_TOKEN`(비어 있으면 관리자 기능 차단), `MEDIA_DIR`(기본 `./media`, git 제외)

## 5. 확인하지 못한 것 / 남은 일

- 작은 화면(iPhone SE)은 이번 변경분 재검증 필요 (7단계 전체 모바일 검증에서)
