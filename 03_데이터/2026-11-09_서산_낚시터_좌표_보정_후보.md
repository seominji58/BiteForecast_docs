## 4. 추가로 발견한 문제 — 창리해상낚시터 (id 176)

- 원본 주소: 충청남도 서산시 부석면 창리 지선 / 원본 좌표 36.369181, 126.224581
- 이 좌표는 역지오코딩하면 **보령시 앞바다**다. 서산 부석면 창리(천수만 북쪽)와 수십 km 떨어져 있어 **이것도 잘못된 좌표일 가능성**이 있다.
- 지금 「좌표 의심」 규칙은 같은 시·도(충남) 안에서 틀린 경우를 잡지 못한다 → 아직 정상으로 처리되고 있다. 해황(파고·특보)이 보령 앞바다 기준으로 연결돼 있을 수 있다.

## 5. 결정 요청

1. **좌표 확인 방법**: (가) VWorld 또는 도로명주소 API 인증키 신청 → 지번 좌표 확인 (나) 서산시 해양수산과 문의 (다) 지적도로 사람이 직접 확인
2. **확인 전 처리**: 지금처럼 6곳 제외 유지 (권장)
3. **창리해상낚시터**: 확인될 때까지 6곳과 같이 「위치 확인 필요」로 둘지
4. 보정 시: 원본 좌표는 남기고(예: `lat_source`, `lon_source`), 보정 좌표·출처·확인일·정밀도(육상 기준점/좌대 확인)를 함께 기록한다 — 스키마 변경 필요
