## 1. 조사 방법

| 항목 | 방법 |
|---|---|
| 출처 구분 | `place_info.source` (공공데이터 표준 / 국립해양조사원 지점 / 수동 지정) |
| 원문 좌표 | 공공데이터 원본 CSV(`낚시터정보.csv`, 바다 177곳 중 좌표 있는 163곳)의 `WGS84위도·경도` **글자 그대로** |
| 실질 정밀도 | 끝자리 0을 뺀 자릿수. 위도·경도 중 더 정밀한 쪽. 소수 3~4자리이면서 1/60도의 배수이면 「분 단위(±0.9km)」. 끝자리를 0으로 채운 값은 「반올림 의심」 |
| 같은 좌표 공유 | 소수 6자리까지 같은 좌표를 쓰는 곳 묶음, 주소가 같은지 |
| 주소·행정구역 | 도로명·지번 주소의 시·군 일치. 좌표가 주소의 시·군 쪽에 있는지는 **대리 점검**(같은 시·군의 가장 가까운 곳 vs 다른 시·군의 가장 가까운 곳) |
| 연결 안정성 | 가장 가까운 조위관측소·부이의 1·2위 거리 차가 좌표 오차보다 작은지, 30km 연결 기준 경계, 기상청 예보격자(5km) |
| 좌표 의미 | 근거가 있을 때만 「추정」, 없으면 「확인 불가」 |

**한계:** 좌표 → 행정구역 역지오코딩과 해안선(육지/바다) 판정 자료는 쓰지 않았다(외부 API·키 필요). 그래서 행정구역 대조는 **대리 지표**이고, 확정이 아니다.

## 4. 주소 · 행정구역 일치

**구조상 주의:** 공공데이터 낚시터의 시·군(`region`)은 **주소에서 만들었다**(`scripts/build_places.py` `region_from_address`). 그래서 「주소 ↔ 행정구역」은 구조적으로 늘 일치한다. 확인해야 하는 것은 **좌표가 그 시·군에 있는지**다.

| 점검 | 결과 |
|---|---|
| 도로명·지번 주소의 시·군 일치 | 1곳 형식 문제: 송정유료낚시터(108) 도로명 주소에 「울주군」이 빠짐 (`울산광역시 서생면 …`). 위치 문제 아님 |
| 좌표가 다른 시·군 쪽 (대리 점검) | 서산 6곳(부산 해운대구 쪽) · 창리(태안군 쪽) · **신안낚시터(무안군 쪽)** · 국립해양조사원 2곳(부산동부·하리항남서 — 지수 지점 시·군을 좌표로 정했기 때문에 경계 오탐) |

## 6. 좌표 품질 등급 설계

| 등급 | 기준 | 필요한 근거 | 올라가는 조건 |
|---|---|---|---|
| **A** 실제 낚시 위치 검증 | 실제 좌대·포인트 위치와 좌표의 차이가 허용 범위(예: 200m) 안 | 지자체 신고서 위치도, 업체 확인, 현장 확인, 항공사진 대조 중 1개 이상 + 확인일 | — |
| **B** 대표 위치 확인 | 공신력 있는 자료로 대표 위치(기관 지점, 항구, 주소지 건물·필지)가 확인됨 | 기관 좌표, 또는 행안부·국토부 주소 좌표와 원본 좌표의 차이가 허용 범위 안 | 실제 위치 확인 → A |
| **C** 정밀도 부족·실제 위치 미확인 | 좌표 오류 근거는 없지만 확인도 안 됨 | C1: 정밀 좌표(소수 4자리 이상·단독)·의미 미확인 / C2: 실질 정밀도 0.01도 이하, 분 단위, 같은 좌표 공유 | 주소 대조 통과 → B |
| **D** 좌표 오류 의심 | 다른 시·도 좌표, 주소와 다른 해역, 주소 대조 결과 큰 차이 | 자동 규칙(시·도 이웃 비교) 또는 사람이 확인한 근거 | 근거 있는 보정 승인 후 → B 또는 C |

- **소수 자릿수만으로 등급을 정하지 않는다**: C1/C2 는 「확인 안 됨」 안에서의 세부 구분일 뿐이다.
- 대리 점검(좌표가 다른 시·군 쪽)만으로는 D로 올리지 않고 **우선 검토**로 둔다. 그래서 신안낚시터는 C이고, 국립해양조사원 2곳은 B다.

  - ③ 같은 좌표 묶음을 지도에서 고를 수 없다.

## 14. 진행 결과 (2026-11-09, 사용자 승인: 단계 0·1)

### 단계 1 — 좌표 검증 기록 (`place_coord_check`)

- 칸: 등급·세부·위치 유형·검증 상태·확인 출처(method·source_ref)·보정 후보(candidate_lat/lon/note)·판단 근거·검증 일시·batch·확인자
- **이력 보존**: 기록은 추가만 한다. 장소의 현재 상태는 가장 최근 기록이다. `place` 에는 칸을 더하지 않았다(중복 최소화).
- **마이그레이션**
  - 백업: `backups/biteforecast-20261109-185657-before-coord-check.db`
  - 등록: `scripts/coord_checks.py register … --batch audit-2026-11-09` → 219건 (A 0 · B 49 · C 163(C1 85 · C2 78) · D 7, 검토 필요 32)
  - 등록 전후로 원본 좌표·행 수가 같은 것을 확인했다.
- **롤백**
  - `rollback --batch audit-2026-11-09` 는 기록만 지운다.
  - `drop-table` 은 기록이 남아 있으면 거부한다.
