# 외부 API

> 인증키 **값은 이 문서와 Git 에 두지 않는다.** 표의 「키」는 `backend/.env` 의 변수 이름만 적는다.

## 앱 데이터 (공공데이터, 수집기가 주기적으로 받아 DB 에 저장)

| 제공 기관 | API (공공데이터포털) | 앱에서의 용도 | 키 | 상태 |
|---|---|---|---|---|
| 국립해양조사원 | 조석예보(고·저조) `tideFcstHghLw` | 만조·간조 시각과 높이 | `DATA_GO_KR_API_KEY` | ✅ 사용 중 |
| 국립해양조사원 | 조석예보(시계열) `tideFcstTime` | 물때 그래프(시간별 조위) | 〃 | ✅ 사용 중 |
| 국립해양조사원 | 해양관측부이 최신 관측 `twRecent` | 파고·풍속·수온 실측 | 〃 | ✅ 사용 중 |
| 국립해양조사원 | 바다낚시지수 `fcstFishingv2` | 어종별 공식 낚시지수(오전·오후·하루), 물때 | 〃 | ✅ 사용 중 |
| 국립해양조사원 | 조류예보 | 조류 세기·방향 | 〃 | ⏸ 인증키에 서비스 미등록 — 보류 ([조류예보 연결 검증](2026-11-10_조류예보_API_연결검증.md)) |
| 기상청 | 단기예보 `VilageFcstInfoService_2.0/getVilageFcst` | 파고(WAV)·풍속(WSD)·기온(TMP)·강수확률(POP)·하늘(SKY)·강수형태(PTY) | 〃 | ✅ 사용 중 |
| 기상청 | 기상특보 현황 `WthrWrnInfoService/getPwnStatus` | 해상 특보·예비특보 | 〃 | ✅ 사용 중 |
| 공공데이터포털 | 전국낚시터정보표준데이터 (파일) | 낚시터 목록(바다 유료 낚시터) | 없음 (파일 내려받기) | ✅ 낚시터 목록 생성 때 1회 |

- 수집 주기: **매시 17분** GitHub Actions 에서 1회 (Mac 꺼져도 동작) → Supabase 에 저장
- 호출 간격 0.4초, 429(호출 과다)면 재시도, 같은 발표분은 다시 받지 않음
- 검증 기록: [공공 API 검증 결과](공공API_검증결과.md)

## 로그인

| 서비스 | 용도 | 키 | 상태 |
|---|---|---|---|
| Google 로그인(OAuth) | 구글 계정 로그인 — 서버는 구글 공개키(`googleapis.com/oauth2/v3/certs`)로 토큰만 검증 | `GOOGLE_CLIENT_IDS` | ✅ (클라이언트 ID 설정 시) |
| 자체 이메일 로그인 | 이메일·비밀번호 (비밀번호는 해시로만 저장) | — | ✅ |

## 운영 인프라

| 서비스 | 용도 | 지역·요금 | 설정 위치 |
|---|---|---|---|
| Supabase (PostgreSQL) | DB | 서울(ap-northeast-2) · Free | `DATABASE_URL` (Fly·GitHub 비밀값, 로컬 `.env`) |
| Fly.io | 백엔드 API 서버 `https://biteforecast-api.fly.dev/api/v1` | 도쿄(nrt) · 종량제(월 약 $2 이하 예상) | `fly secrets` |
| GitHub Actions | 해황 자동 수집 (매시 17분) | 공개 저장소 무료 | 저장소 Secrets |

- 문서: [서버 배포](서버_배포.md) · [DB (Supabase)](DB_Supabase.md) · [자동 수집](../06_개발환경/자동_수집.md)

## 개발·검증 전용 (앱 사용자 화면에는 쓰지 않음)

| 서비스 | 용도 | 키 | 비고 |
|---|---|---|---|
| 행정안전부 주소 검색 API (juso) | 낚시터 주소 ↔ 좌표 대조 검증 | `JUSO_SEARCH_KEY` | 검증 스크립트 전용, 결과는 상태·판정만 저장 |
| 행정안전부 좌표제공 API | 주소 → 좌표 대조 | `JUSO_COORD_KEY` | 키 미발급 — 보류 |
| VWorld 주소 API | 주소 → 좌표 대조 | `VWORLD_API_KEY` | 약관상 좌표·주소를 DB·Git 에 저장하지 않음 |
| OpenStreetMap Nominatim | 낚시지수 지점의 지역명(역지오코딩) | 없음 | 낚시터 목록 만들 때만, 초당 1회 이하, 결과 캐시 |
| OpenAI 이미지 API (`gpt-image-2.6-flare`) | 어종 일러스트 15종 생성 | `OPENAI_API_KEY` | 로컬 스크립트 전용·앱 번들에 키 없음, 누적 약 $0.74 |

- `RDA_API_KEY` (농촌진흥청) 는 `.env` 에만 있고 현재 코드에서 쓰지 않는다
