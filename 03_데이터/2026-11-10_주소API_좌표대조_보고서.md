**VWorld 결과 저장**

- VWorld 이용약관과 지오코더 가이드에 「별도의 저장장치나 데이터베이스에 저장할 수 없습니다」라고 되어 있다.
- 그래서 좌표·정제 주소는 **어디에도 저장하지 않았다**. 메모리에서 거리 계산에만 썼다.
- 거리 같은 **파생값을 저장해도 되는지는 공식 문서에 없다**. 그래서 저장소 CSV에는 거리 값을 넣지 않고 **상태와 판정만** 남겼다.
- 이 보고서에는 **구간별 집계만** 적었다.
- 정확한 거리는 개발 PC에서 다시 계산할 수 있다(`--public` 없이 실행, 저장소에 올리지 않음).
- 파생값 저장 범위는 VWorld 운영기관에 확인을 요청할 것을 권한다(고객센터 1661-0115).

## 2. 인증키 · API

### 2-1. 인증키 (값은 출력하지 않았다)

| 환경 변수 (`backend/.env`) | 상태 | 비고 |
|---|---|---|
| `DATA_GO_KR_API_KEY` | 설정됨 | 공공데이터포털 — **변경하지 않음** |
| `JUSO_SEARCH_KEY` | 설정됨 | 처음에는 이름 앞에 `d` 가 붙어 있었다(`dJUSO_SEARCH_KEY`). 이름만 고치고 값은 그대로 뒀다. **API가 키를 거부함 (4.1)** |
| `JUSO_COORD_KEY` | **없음** | 행정안전부 「좌표제공 API」 키 — 주소 좌표를 받으려면 필요 |
| `VWORLD_API_KEY` | 설정됨 | 정상 동작. 서버 측 호출에서 도메인 오류는 나지 않음 |

- `.env` 는 `.gitignore` 에 들어 있어 저장소에 올라가지 않는다.
- 키가 들어간 요청 URL과 응답 원문은 스크립트가 출력하지 않는다. 오류는 종류(예: `HTTP 500`, `E0001`)만 기록한다.

### 2-2. 사용한 API 와 조건 (공식 문서 기준)

| 항목 | 행정안전부 도로명주소 **검색 API** | VWorld **지오코더 2.0** (getcoord) + 역지오코딩 (getaddress) |
|---|---|---|
| 도로명 주소 검색 | 됨 (keyword) | `type=road` |
| 지번 주소 검색 | 됨 (지번 우선 정렬 `firstSort=location`) | `type=parcel` |
| 좌표 | **주지 않음**. 별도의 「좌표제공 API」(건물 단위, 키 따로) | 줌 (EPSG:4326 위경도, 변환 불필요) |
| 좌표계 | 좌표제공 API는 UTM-K → 위경도 변환 필요 | 기본 EPSG:4326 |
| 정확도·한계 | 결과가 여러 개일 수 있음 → **임의 선택 안 함**(「다중 결과」) | 한 결과만 줌. 「지선」·항구 이름은 처리 못 함. 「산」 번지를 일반 번지로 바꿔 돌려주는 경우 있음(1곳) |
| 이용량 | 공식 일일 한도 확인 못 함. 검색 결과 9천 건 초과 검색 불가. 개발키는 기간 만료 | **하루 40,000건** |
| 결과 저장 | 저장을 막는 조항은 찾지 못함(공공데이터포털: 이용허락범위 제한 없음). business.juso.go.kr 약관 원문은 확인 못 함 | **저장 금지** — 「별도의 저장장치나 데이터베이스에 저장할 수 없습니다」, 「오픈플랫폼에서 제공되는 데이터는 무단으로 저장하지 못합니다」 |
| 이번 처리 | 키 미승인으로 호출 결과 없음 | 좌표·정제 주소 **저장 안 함**. 판정·상태만 저장. 거리는 집계만 보고 |

출처: business.juso.go.kr 검색API 안내, data.go.kr 15057017·15101106, vworld.kr 지오코더 2.0 가이드·이용약관(v4po_prcint_a001).

- 행정안전부 API가 키를 거부해 **두 API의 비교는 하지 못했다**.

  - 원본 도로명·지번 주소가 서로 다른 장소를 가리키는 것으로 보인다.
  - 이름에 「폐업」이 붙어 있어 **운영 여부도 확인해야 한다**.

## 4. 확인이 필요한 것

### 4-1. 행정안전부 키 (사용자 확인 필요)

- 검색 API, 좌표제공 API, 영문 API, 그리고 business.juso.go.kr와 www.juso.go.kr 두 주소 모두에서 `E0001 승인되지 않은 KEY` 가 나왔다.
- 도로명주소 승인키는 보통 `U01…`(운영) 또는 `devU01…`(개발)로 시작하는데, 등록된 값은 그렇지 않다.
- 확인할 것:
  1. 복사한 값이 「승인키」가 맞는지 (신청번호·인증번호가 아닌지)
  2. 신청한 API가 「도로명주소 검색 API」인지
  3. 승인 상태와 기간
  4. 좌표까지 대조하려면 「좌표제공 API」 키도 따로 받아 `JUSO_COORD_KEY` 로 넣기

- **행정안전부 결과 없음 + VWorld 찾음 18곳**:
  - 서산 7곳(D), 태안 지선 일부, 통영 도동 등이다.

### 행정안전부 좌표제공 API 준비

- `JUSO_COORD_KEY` 를 `.env` 에 넣으면 `verify_addresses.py` 가 자동으로 쓴다.
  1. 검색에서 한 건으로 맞은 주소의 건물 좌표(UTM-K)를 받는다.
  2. 위경도로 바꾼다(`app/core/utmk.py`, 왕복 오차 1cm 미만 테스트).
  3. 원본 좌표와의 거리, VWorld 좌표와의 거리를 계산한다(「같은 곳 ≤0.1km / 조금 다름 / 다름 — 원인 확인」).
- 키가 없으면 「건너뜀」으로 기록하고 나머지는 그대로 동작한다.
- 저장소용 CSV(`--public`)에서는 두 API 좌표에서 계산한 거리도 뺀다.
