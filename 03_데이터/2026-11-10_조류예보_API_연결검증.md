# 국립해양조사원 조류예보 API 연결 검증

검증일: 2026-11-10

## 결론

조류예보(시계열)는 저장·DB·UI에 추가하지 않았다. 현재 인증키가 이 서비스에 등록되지 않아 실제 지점 목록과 응답을 받을 수 없으므로, 219개 낚시터 연결률은 0%로 보지 않고 **산출 보류**로 남긴다.

현재 좌표 검증 정책을 적용하면 연결 후보는 다음과 같다.

| 항목 | 수 |
|---|---:|
| 활성 낚시터 | 219 |
| 최근 좌표 검증 D등급(핀·목록 제외) | 7 |
| 조류예보 연결 후보(219-7) | 212 |
| 실제 조류예보 지점과 30km 이내 연결 | 산출 보류 |

D등급 7곳은 기존 정책대로 API 연결 후보에서 제외한다. 원본 `place.lat/lon`, 좌표 검증 이력 543건, 등급은 변경하지 않았다. 후보 212곳도 실제 조류예보 지점과의 거리·해역 관계를 확인하기 전에는 연결된 것으로 표시하지 않는다.

## 공식 명세

- 데이터셋: [해양수산부 국립해양조사원 조류예보(시계열)](https://www.data.go.kr/data/15156024/openapi.do)
- 배포 기본 경로: `https://apis.data.go.kr/1192136/crntFcstTime`
- 오퍼레이션: `GetCrntFcstTimeApiService`
- 주요 요청: `obsCode`(필수), `reqDate(yyyyMMdd)`, `min(최대 60)`, `type=json`, `numOfRows(최대 300)`
- 주요 응답: `obsvtrNm`, `lot`, `lat`, `predcDt`, `crdir(16방위)`, `crsp(cm/s)`
- 제공 범위: 관할해역 약 200개 예보지점, 현재 연도 자료. 포털 설명에는 연 1회 지점·자료 갱신, API 정보에는 실시간 업데이트로 기재되어 있어 실제 운영 시 `predcDt`와 `fetched_at`을 함께 확인해야 한다.
- 이용 조건: 무료, 공공저작물 출처표시 제1유형, 개발계정 신청 트래픽 10,000건(포털 안내). 운영계정은 활용사례 등록 후 증량 신청.

## 실제 호출

공식 활용가이드의 예시 지점 `16LTC10`과 오늘 날짜를 사용해 실제 호출했다. 응답은 다음과 같다.

```text
returnReasonCode 30
등록되지 않은 서비스키
```

이는 파라미터 오류나 자료 결측이 아니라, 현재 인증키에 해당 조류예보 서비스 활용 권한이 없다는 뜻이다. 외부 호출을 반복하지 않았고, 새 키 발급·활용신청은 사용자 승인 전 진행하지 않는다.

## 연결 방법(구현 보류안)

서비스가 승인된 뒤 한 번만 지점 목록을 확보하고, 지점의 `lat/lon`을 기준으로 다음 순서로 검증한다.

1. D등급 7곳과 좌표 검증 보류 장소는 제외한다.
2. 후보 212곳 각각에 대해 가장 가까운 조류예보 지점을 계산한다.
3. 기존 관측소 연결 정책과 같은 30km 상한을 적용하되, 실제 낚시터 위치가 아닌 대표 주소·항구 좌표인 경우 거리만으로 ‘현장 조류’라고 표현하지 않는다.
4. 장소와 조류예보 지점의 해역이 불명확하면 `자료 연결 불가/확인 필요`로 둔다.
5. 연결률은 `거리·해역 검증을 통과한 후보 수 / 212`로 계산하고, API 응답이 없는 날은 결측으로 기록한다.

유속·유향은 조류의 물리적 상태 참고자료로만 제공한다. 입질·조과·어획 확률이나 출조 적합성을 계산하지 않는다.

## 다음 승인 후 작업

조류예보 서비스 활용신청이 승인되면 샘플 1개 지점으로 응답 형식과 `predcDt/crsp` 결측을 재검증한 뒤, 지점 목록 전체를 받아 212곳 연결률을 산출한다. 그 결과와 호출량을 먼저 보고한 다음에만 저장 구조·상세 화면 연결 여부를 결정한다.
